Запит на оплату

Заповніть усі поля — запит одразу потрапить до бухгалтера.

Як це працює
  1. Один запит — один платіж. Якщо платежів кілька, подайте кілька запитів.
  2. У реквізитах вкажіть усе, що потрібно для оплати: IBAN, отримувач, ІПН/ЄДРПОУ, банк. Для USDT — адресу гаманця й мережу.
  3. Після «Надіслати» ви отримаєте код запиту, а бот надішле його вам у чат. Збережіть код — за ним бухгалтер знайде ваш запит.
  4. Бухгалтер звірить реквізити та проведе оплату в погоджену дату.
